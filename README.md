# Secure Email Analyzer

## Description
Application web Java permettant d'analyser des emails
afin d'estimer un risque de phishing.

## Features
- Authentification (register / login)
- Analyse d'emails suspects
- Score de risque
- Interface web simple

## Tech Stack
- Java 21
- Spring Boot
- Spring Security
- H2 / PostgreSQL
- HTML / CSS / JS

## How to run
```bash
./mvnw spring-boot:run
