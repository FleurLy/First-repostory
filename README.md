# Secure Email Analyzer

Spring Boot application to detect suspicious emails using rule-based analysis.

## Features
- User authentication (Spring Security)
- Secure registration with password validation
- Email analysis (keywords + score)
- Analysis history per user

## Tech Stack
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Thymeleaf
- H2 / MySQL

## How to Run
- mvn spring-boot:run
- http://localhost:8080/login
